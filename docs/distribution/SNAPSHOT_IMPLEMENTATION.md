## Implementación
[Resolver](../../tools/system-lab/resolve_snapshot.sh) invoca Pacman dentro de builder descartable, root y DB vacíos, sin instalar paquetes, sin hooks ni mounts de host salvo evidencia y script read-only. Solo repos fechados; sin fallback rolling ni partial upgrades. Pacman genera closure, [lock](../../tools/system-lab/snapshot_lock.py) valida formato, arquitectura, URL, hashes, duplicados y paquetes solicitados. Guarda bases de datos originales y hashes, versión Pacman y digest builder. Esta etapa solo verifica estructura de metadata recibida por HTTPS y resolución; SigLevel Required DatabaseOptional es política de configuración, no prueba de autenticidad de todos los paquetes. Lock candidato explicitly package_signatures_verified=false, release_signed=false. No descargar/instalar paquetes antes de verificar su firma y hash contra una cadena de confianza revisada. No publicar lock como release ni asumir reproducibilidad hasta segunda resolución y build.
