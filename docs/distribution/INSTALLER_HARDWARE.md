# Instalador, hardware y recuperación
Fuentes: [Archiso](https://wiki.archlinux.org/title/Archiso), [Calamares](https://github.com/calamares/calamares), [Secure Boot](https://wiki.archlinux.org/title/Unified_Extensible_Firmware_Interface/Secure_Boot), [Btrfs](https://wiki.archlinux.org/title/Btrfs).
Archiso candidato para ISO, Calamares candidato si permite instalar layout atómico, cifrado y boot sin alterar imágenes activas; evaluar integración antes de elegir. UEFI primero como propuesta, BIOS legacy evaluar según hardware y alcance, no eliminar sin decisión. GPT/ESP/XBOOTLDR según backend, Btrfs y LUKS2, home/datos persistentes, espacio para múltiples versiones y snapshots, recovery separado o ISO. Detectar dual boot y discos, preview exacto antes de formatear, consentimiento, no destruir datos ajenos. TPM/enrollment/Secure Boot y claves propias requieren UX y recovery; no garantizar soporte universal. Secure Boot firma UKI/bootloader, módulos política separada. Firmware, GPU, Wi-Fi, Bluetooth, audio, suspensión, cámaras, multi-monitor y medios USB. Pruebas RTX3090 + presión VRAM, GPU legacy y iGPU, KVM no sustituye hardware. Instalación con/sin red, actualización interrumpida, recovery offline, rollback datos y reinstalación preservando home según consentimiento. No se decide layout definitivo ni se modifica sistema real.

## Instalación y experiencia
Archiso como medio candidato; Calamares tiene fases view/job y módulos de particiones/mount/unpackfs/bootloader, pero el layout atómico requiere integración específica y pruebas. [Calamares modules](https://github.com/calamares/calamares/blob/calamares/src/modules/README.md). ISO debe incluir la base necesaria para instalar y recuperar offline; Flatpaks adicionales pueden requerir Internet, indicar antes. UEFI + systemd-boot/UKI y LUKS2 candidatos, no seleccionar sin prueba. Mantener claves de recuperación, no eliminar claves firmware de terceros automáticamente. Primera instalación, asistente inicial y recuperación con SupraUI cuando maduro; adaptar Calamares antes de reescribir particionador. [UX](USER_EXPERIENCE.md), [trust](TRUST_BOOT.md), [datos](STATE_RECOVERY.md).
