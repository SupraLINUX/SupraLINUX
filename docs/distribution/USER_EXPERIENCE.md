# Experiencia de instalación, actualización y recovery
Estado: dirección ACCEPTED por mantenedor, diseño PROPOSED, pruebas NOT_RUN. Público primario: usuario poco experimentado que quiere procesos visualmente cuidados. No exigir terminal. UI SupraUI y tokens, acciones tipadas compartidas con CLI y agentes sujetos a permiso; modo avanzado bajo demanda, no ocultar riesgos ni inventar progreso.
## Software
Vista Applications universal y catálogo con origen claro, búsqueda por nombre, icono, descripción, versión y proveedor; Flatpak recomendado si compatible; AppImage/AppDir portable, AUR integrado/restringido/host elegibles. Explicar con una frase dónde se instala, acceso a datos, reinicio y confianza. AUR oficial de comunidad no equivale a revisado por distro. Elegir destino con sugerencia y alternativa; no bloquear instalación legítima solo por complejidad, no desactivar protecciones. Vista avanzada: dependencias, PKGBUILD/changes, permisos, log y conflicto; no autoejecutar al drop. Instalación muestra descarga/build/validación/staging; progreso determinado solo si total conocido, si no indeterminado. Cancelar solo cuando safe; comunicar fase no cancelable. Mostrar instalado vs pendiente reinicio. Desinstalación por proveedor, conservar datos por defecto, informar si otras apps usan dependencia.
## Actualización
Pantalla sencilla: versión disponible, cambios y avisos, bytes y espacio estimado, requiere reinicio, capas incompatibles, actualizar ahora o programar localmente con consentimiento. Descargar/stage sin bloquear uso; avisar antes de reinicio y cambios no guardados, nunca reiniciar sorpresa. Offline y energía insuficiente: explicación y reintento. Errores accionables, no volcar log técnico en pantalla principal. Recuperación: «Se volvió a la versión anterior; tus documentos no se modificaron por el rollback» solo cuando confirmado, mostrar capa problemática y opciones. No decir documentos intactos si no hay evidencia; distinguir backup/rollback. Modo recuperación offline si shell no inicia.
## Instalación inicial
Idioma, teclado, accesibilidad, disco/dual boot, cifrado y recuperación, cuenta local, progreso real, primer inicio sin cloud ni IA obligatoria. Confirmación independiente de formateo/disco exacto. Apariencia coherente, reduced motion, teclado y lector de pantalla. Asistente avanzado opcional. Usar Calamares adaptado mientras SupraUI madure, no duplicar particionador sin necesidad.
## Aceptación
Pruebas con usuarios nuevos: instalar Flatpak/AppImage/AUR, entender cambio host y reinicio, actualización normal/fallo, cancelar, recuperar sin terminal, quitar app preservando datos. Medir completion, errores, comprensión, pasos y latencia; no inventar métricas. UI/CLI/MCP muestran mismo estado de transacción, agentes no saltan confirmación.
## Ratificación de alcance visual
La instalación inicial, progreso, actualización, error y recovery deben compartir lenguaje de diseño 1:1 macOS (excepto recursos artísticos/identidad originales o libres auditados). Frontend Calamares se adapta sin cambiar lógica solo por razones estéticas; no ocultar consentimiento, particiones, cifrado ni errores. [Frontend](INSTALLER_FRONTEND.md). Beginner First no obliga a eliminar opciones avanzadas.
