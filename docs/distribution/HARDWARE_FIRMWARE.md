# Hardware y firmware
Fuentes: [LVFS](https://lvfs.readthedocs.io/en/latest/intro.html), [fwupd client](https://fwupd.github.io/libfwupd/class.Client.html), [device emulation](https://fwupd.github.io/libfwupdplugin/device-emulation.html), [fwupd UEFI capsule](https://fwupd.github.io/libfwupdplugin/uefi-capsule-README.html), [linux-hardware.org](https://linux-hardware.org/).
## Matriz inicial candidata
VM OVMF + virtio (boot/cifrado/rollback, sin certificar GPU física); Intel iGPU portátil (batería/suspend/Wayland), AMD iGPU/APU y Radeon dedicada (Mesa/Vulkan), NVIDIA Ampere (RTX3090 presión VRAM y CUDA), NVIDIA Pascal legacy si rama compatible; otros GPU según disponibilidad. Monitores 60/144Hz mixtos, escala fraccional, HDMI/DP, hotplug; Wi-Fi/BT, audio, webcam, touchpad, USB, NVMe/SATA, LUKS2, dual boot, juegos Flatpak/nativo. Registrar PCI IDs, firmware, kernel, Mesa/NVIDIA, build y resultados, con reportes opt-in redactados. No inferir compatibilidad de base de datos comunitaria; útil para priorizar, no certificación. Equipos reales pendientes de disponibilidad. No exigir hardware del mantenedor para arrancar escritorio.
## SupraFirmware
Frontend sobre fwupd D-Bus/libfwupd, LVFS metadata, dispositivos/releases, cambios, requisito AC/batería, progreso, resultado, historial, reinicio y actualizaciones offline según plugin. No flasher propio, no distribuir blobs sin derechos. No prometer todos los equipos. Verificar origen a través de fwupd, no instalar firmware desde AUR como sustituto de flujo oficial. Consentimiento separado, no agente ejecutando actualización privilegiada sin aprobación. Evitar confundir rollback OS con firmware: firmware cambia hardware y puede no ser reversible, puede alterar TPM/PCR, Secure Boot y compatibilidad de despliegues anteriores. Actualizaciones firmware y OS coordinadas pero no misma transacción; no programar ambas juntas inicialmente. Emulación fwupd para pruebas de interfaz y errores sin flashear; hardware solo autorizado, condiciones de fabricante y recuperación documentada. LVFS puede aplicar cápsulas antes de bootloader; no interrumpir ni simular rollback firmware real. Todos NOT_RUN.
