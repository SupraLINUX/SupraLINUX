## Trust
Pruebas OVMF con claves de laboratorio, nunca productivas; boot signed, rechazo de artefacto inválido y rollback. Producción: evaluar shim review y firma pública, trust chain firmware y transición certificados Microsoft UEFI CA 2023, SBAT/dbx, claves de distro y módulo local autorizadas, compatibilidad dual boot. No prometer firma comercial ni aceptación de firmware; proceso externo pendiente. Enroll local explícito solo como alternativa documentada, no borrar claves previas. Secure Boot no sustituye integridad root ni backup. No bypass ni claves en repo. Recuperación independiente firmada/verified, sin red; test con shell roto, datos cifrados y medio externo. No asumir que un UKI anterior sigue aceptado después de revocación.
## Instalador
Calamares documentación activa confirma settings.conf, branding y módulos. Prototipo visual QML/QSS + datos sintéticos sin privilegios donde viable; plan de disco y jobs validados separadamente en VM. Mantener particionado, consentimiento y cifrado fiables; job de despliegue atómico específico. Revalidar APIs fuente actual Codeberg antes de patch. No afirmar UI 1:1 sin corpus.
## Infraestructura
CI estándar público GitHub para fmt/lint/docs/unit y build pequeño; runners grandes facturan incluso repos públicos, almacenamiento tiene condiciones; revisar vigentes antes de pagar. QEMU/KVM en runner dedicado si virtualización disponible; GPU real y builds pesados fuera de runner genérico. Runner no confiable para firma, aislar PRs y secretos. Almacenar imágenes y fuentes en HTTP/object storage con hashes, firmas, Range/resume y cuotas. R2 candidato por política de egress directo sin cargo, pero storage/requests y otros servicios cuestan; no compromiso proveedor. Medir coste por build CPU-horas, RAM pico, disco, bytes imagen y caché, retención y descargas. Ejemplo supuesto 3 GB imagen x 1000 descargas = 3000 GB de transferencia, no previsión ni presupuesto real. Coste mensual = compute + storage + requests + transferencia + backups; publicar solo tras dimensionamiento. Primero full image, después delta si mediciones justifican. No publicar imágenes sin autorización.
