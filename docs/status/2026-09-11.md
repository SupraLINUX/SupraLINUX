## Decisions

- Ubuntu 26.04 LTS is the base platform; KDE upstream stable is authoritative for the desktop stack.
- Qt provider selection follows KDE's selected requirement profile.
- SupraLINUX remains a mutable `.deb`/APT/dpkg system.
- GitHub-hosted Ubuntu 26.04 is a **non-authoritative preflight lane**.
- Authoritative build/test execution occurs inside disposable self-hosted **KVM virtual machines running Ubuntu 26.04**.
- The authoritative VM uses per-VM GitHub JIT configuration; persistent runner credentials are not baked into the golden image.
- Pre-merge self-hosted gates use controlled PR labels and refuse fork PRs.
- The authoritative runner VM uses fresh `sbuild/unshare` package-build isolation and `autopkgtest/QEMU` system testing with nested KVM.
- The supported host bootstrap recipe targets Ubuntu 26.04 amd64/x86_64 as an infrastructure provider only.
- Host bootstrap may install/configure the packaged KVM/libvirt stack and standard network, but must not silently alter BIOS/firmware or forcibly reload KVM modules.
- Golden runner images are built from a verified released Ubuntu cloud image by `scripts/build-authoritative-runner-image.sh`; publishing/replacing an existing golden image requires explicit opt-in.
- The golden-image builder must preserve provenance/evidence, perform offline clone-safety cleanup, flatten the preparation overlay, validate the final qcow2 and record its real SHA-256.
- Expensive hosted package builds are gated on the actual PR `synchronize` delta rather than the whole PR-to-base diff.
- Build artifacts and hashes are captured immediately after successful build gates, before later test gates.
- Build graph states are `PASS`, `FAIL` and `BLOCKED`; `BLOCKED` is distinct from `FAIL`.

## Inference

Ubuntu Qt 6.10.2 remains a strong reuse candidate for the current Plasma 6.7 profile, but version-line agreement is not a certification result.

The hosted build path is now independently proven and its expensive repetition is suppressed correctly for unrelated PR updates. This reduces CI noise/cost without weakening the package gate.

The repository now contains the full intended repository-side chain for Phase 1: host bootstrap/preflight, verified Ubuntu source-image fetch, automatic golden-image construction, JIT one-job runner lifecycle, authoritative runner contract, authoritative `sbuild` and nested `autopkgtest/QEMU` proof. This is implementation completeness, not execution certification.

## Implementation now available

- `.github/workflows/runner-contract.yml` checks Ubuntu 26.04, KVM virtualization, `/dev/kvm`, QEMU/KVM capability, toolchain and prepared test image.
- `.github/workflows/authoritative-package-proof.yml` performs authoritative `sbuild` followed by `autopkgtest/QEMU` when a certified runner is available.
- `scripts/provision-kvm-host.sh` installs/configures the supported Ubuntu 26.04 host KVM/libvirt toolchain without forcing nested-KVM module changes.
- `scripts/check-kvm-host.sh` is the read-only gate for CPU virtualization, `/dev/kvm`, groups, nested KVM, QEMU/libvirt/libguestfs and network state.
- `scripts/fetch-ubuntu-26.04-cloud-image.sh` verifies Ubuntu's signed released-image checksum metadata before accepting the base image.
- `scripts/build-authoritative-runner-image.sh` automates preparation VM creation, exact source-commit checkout, guest provisioning, nested QEMU test image generation, seal, evidence export, offline sysprep, flatten/check and final golden-image SHA-256/provenance.
- `scripts/install-actions-runner.sh` verifies the SHA-256 digest published in GitHub release metadata before installing runner software.
- `scripts/run-kvm-jit-gate.sh` implements one-job JIT overlay execution, controlled PR gate triggering, result resolution, diagnostic export and cleanup.
- `scripts/package-preflight-needed.sh` owns the hosted proof event-delta path policy.
