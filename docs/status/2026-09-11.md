# Project status — 2026-09-11

This document intentionally separates facts, decisions, inferences, pending work and blockers.

## Facts

- The project repository was empty before the bootstrap commit created on 2026-09-11.
- Ubuntu 26.04 LTS uses the series name `resolute`.
- KDE's latest stable Plasma release observed on 2026-09-11 is **6.7.5**, released 2026-09-08.
- KDE's latest stable Frameworks release observed on 2026-09-11 is **6.30.0**, released 2026-09-09.
- KDE's latest stable Gear release observed on 2026-09-11 is **26.08.1**, released 2026-09-10.
- KDE's Plasma 6 schedule documents **Qt 6.10** for Plasma 6.7.
- Ubuntu 26.04 currently exposes `qt6-base-dev` **6.10.2+dfsg-7**.
- GitHub currently exposes the `ubuntu-26.04` hosted runner label and describes the image as public preview.

## Decisions

- Ubuntu 26.04 LTS is the base platform.
- KDE upstream stable is authoritative for the desktop stack.
- Qt provider selection follows KDE's selected requirement profile.
- SupraLINUX remains a mutable `.deb`/APT/dpkg system.
- Repository workflows must use an explicit Ubuntu version rather than `ubuntu-latest`.
- Authoritative package builds will use clean sbuild environments on disposable self-hosted Ubuntu 26.04 VMs.
- Build graph results use `PASS`, `FAIL` and `BLOCKED`, with `BLOCKED` distinct from `FAIL`.

## Inference

Ubuntu Qt 6.10.2 is a strong reuse candidate for the current Plasma 6.7 profile because it matches the Qt 6.10 line selected by KDE. Version-line agreement alone is insufficient to claim package/runtime compatibility.

## Pending certification

- build the first clean Debian package under sbuild on the approved runner model;
- capture `.changes` and `.buildinfo` evidence;
- establish autopkgtest/QEMU smoke testing;
- implement repository publication/promotion;
- ingest KDE source metadata and construct the real dependency DAG;
- build Frameworks/Plasma/Gear against the selected Qt provider;
- certify Qt module coverage and private-API consumers;
- test Ubuntu and third-party application compatibility when shared libraries are replaced;
- implement image/recovery integration and Btrfs/Snapper policy.

## Blocked

No architecture blocker is known at this bootstrap stage. The self-hosted authoritative runner is not yet represented by certification evidence, so authoritative package-build status is **pending**, not blocked and not failed.
