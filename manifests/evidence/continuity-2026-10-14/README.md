# Selected continuation inputs

These are exact copies of previously local review inputs, not new package
certifications or lifecycle admissions. The [handoff](../../../docs/handoff/chatgpt-2026-10-14.md)
explains scope, pending gates and host restrictions.

`copied-inputs.json` maps original local paths to repository copies and SHA256.
Embedded `.work/` and `.artifacts/` paths in original records retain provenance;
they are not cloud-accessible paths. `local-retention-catalog.json` inventories
local archives without claiming an off-host backup.

KGlobalAccelD `proposed-debian/` is the latest staged overlay (including the amd64
template minimum correction), outside live packaging. `reentry-review/` contains
the four runtime matrices, exact pins, strict private negative, symbol/import
reviews and cleanup. Aggregate semantic admission validation remains pending.
`runtime-source/` preserves the corresponding local operator/client sources,
including historical materializer variants; read their evidence before use.

`host-operators/` preserves the exact generic operators used for the last CLI
gate. These are historical inputs requiring an authorized execution host and
current applicable gates. This directory does not start or authorize any VM.
LibKSysGuard upstream responses have the recorded query date/pagination limits.
KGamma has source/runtime scope review only. Full private captures, images and
binary archives remain outside Git.
