# SupraLINUX

Distribución Arch Linux atómica con SupraDesktop como escritorio oficial independiente. Objetivo: experiencia macOS 1:1, AI Ready y Beginner First; paquetes coherentes, actualizaciones recuperables, Applications universal y capas Arch/AUR opcionales.

Estado: investigación M00, sin imagen arrancable ni release. Arkdep es candidato a adaptar, no backend definitivo.
